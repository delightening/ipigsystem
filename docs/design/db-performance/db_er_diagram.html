ER 子圖採「鍵欄位視圖」：每個實體只列 PK 與 FK 欄位（非全部欄位），維持可讀性。 FK 關係線上標註子欄位名；⚠noidx 表示該 FK 子欄位目前無支援索引。

① 領域依賴總覽

方塊 = 業務領域（含表數）。粗實線 ==> = 跨域業務 JOIN 外鍵（標 FK 數）；虛線 -.-> = 指向 users 的審計欄位（created_by / updated_by 等，聚合計數）。此分流對應效能診斷：業務 JOIN FK 優先補索引，審計欄預設不補。
