2. 五種標準尺寸

semantic 名稱 → Tailwind max-w-* → 像素 → 用途。未來只透過 <DialogContent size="…"> 指定，不再各處硬編。

3. 現有 16 種 → 5 標準 對照

現有寬度歸入標準說明
max-w-sm / max-w-md / 硬編 425·450·500px→sm (448px)確認框、2FA、刪除原因、單欄極簡
max-w-lg（預設+顯式，~103 處）/ 硬編 600px→md (512px) 預設絕大多數 CRUD 表單，維持現狀
max-w-xl / max-w-2xl / max-w-3xl / 硬編 860px→lg (672px)較大 / 雙欄表單（新增動物等）
max-w-4xl / 硬編 900·1100px→xl (896px)寬內容 / 多欄 / 含表格 — 匯入體重 dialog 落這
max-w-5xl / 硬編 1200px / w-[90vw]→2xl (1152px)資料密集檢視（稽核紀錄、計畫比對）

註：3xl(768px) 6 個 detail dialog 歸 lg 或 xl 視內容於遷移時逐一決定；其餘為機械式對應。

4. 匯入體重 dialog 建議

每列「耳號 + 前 3 次測量 + 今天輸入」約 6 欄，建議 xl (896px)。在 1280px 螢幕約佔 70%、1440px 約 62%。若你覺得還要更寬可選 2xl (1152px) — 用上方滑桿+chip 比對後告訴我。
