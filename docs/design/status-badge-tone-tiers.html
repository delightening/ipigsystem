狀態色兩階 · Solid / Soft 選階規範

DESIGN.md §3.4 · 每個 status 語意色刻意保留兩階，依「密度」選階（非二選一統一）· 2026-07-04

問題：全站狀態色出現兩種長相並存——（1）飽和底＋白字（solid）、（2）淺底＋深字（soft）——跨頁一比顯得不一致。

結論：不統一為單一種。兩階都保留，訂規則分工並收斂進 StatusBadge（tone prop），禁止再手刻。

判準一句話：成群 / 密集重複 → soft；單顆 / 需搶眼 → solid。
