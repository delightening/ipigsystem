# GLP 列印驗收資料夾

用途：驗收 print-pdf 三份 GLP 文件（巡場報告 / 計畫書 / 豬隻欄位表）的**內容與版面**是否符合預期。
（字型 = 標楷體已修正；此處專注「填進去的資料、欄位位置、版面細節」）

## 資料夾結構

| 子資料夾 | 放什麼 | 說明 |
|---|---|---|
| `expected/` | **你預期的樣子** | 你心中「正確輸出」的長相：可以是手填好的 Word/Excel、列印出來掃描的 PDF、或截圖。每份文件一個檔，檔名含 GLP 編號（如 `AD-02-02-01B_預期.pdf`）。 |
| `input/` | **要渲染的資料** | 我拿來填進表單的真實資料。格式見下方，先跟我確認用哪種。 |

## 對應的三份文件
- 巡場報告 `AD-02-02-01B`
- 計畫書 `AD-04-01-01F`
- 豬隻欄位表 `AD-05-01-02C`

> 官方空白母檔（docx/xlsx + Word 匯出 PDF）已在 `docs/glp-templates/`，不必重放。
