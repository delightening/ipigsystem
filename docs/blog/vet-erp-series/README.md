# 系列《一個獸醫，硬幹一套 ERP》

Jason（獸醫，一人開發＋維運 ipig_system）談「為什麼要做這套 ERP base project」的系列文。
每篇一稿兩用：**Threads 短版**（鉤子＋情緒＋一個洞察）與**部落格長版**（展開細節與設計取捨）。

定調：口語、自問自答、自嘲，刻意露破綻。主軸是「控制成本」與「從做中學」。

**雙軌受眾**：
- **工程師版（已凍結，止於第 4 篇）** —— 火藥味較重，刻意露破綻讓工程師罵得起勁（God App、來罵）。
  00–04 保留原樣不再維護；後續只出二代學版。要工程師版的話，等二代學版寫完再一次改寫。
- **二代學版（主線）** —— 語氣改暖，寫給二代／接班者分享踩坑、拋磚引玉，一起越做越好。
