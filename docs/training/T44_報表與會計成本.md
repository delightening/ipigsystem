# T44 ｜ 報表與會計成本

> **受眾**：倉庫管理員、會計／管理人員　**建議時長**：25 分鐘　**前置**：已完成 T41~T43 ERP 進銷存

## 學習目標

1. 找到並產出各類經營報表。
2. 區分各報表的用途與適用對象。
3. 說明成本摘要與血檢費用報表的差異。

---

## 一、報表中心總覽

路徑：側邊欄 → **ERP** → **報表中心**

| 報表 | 用途 |
|------|------|
| 庫存現況報表 | 各倉庫各品項的即時庫存 |
| 庫存流水報表 | 指定期間的庫存異動明細 |
| 採購明細報表 | 採購單據明細彙整 |
| 銷貨明細報表 | 銷貨單據明細彙整 |
| 成本摘要報表 | 期間內的成本統計 |
| 血檢費用報表 | 血液檢查相關費用彙整 |
| 血檢分析報表 | 血液檢查數據趨勢分析 |

> 採購／銷貨可進一步看**月度彙總**、按供應商／客戶、按產品類別統計。

---

## 二、操作步驟

1. 進入**報表中心**，選擇報表類型。
2. 設定篩選條件（期間、倉庫、供應商／客戶等）。
3. 產生報表，可檢視或匯出。

---

## 三、報表選用指引

- 想知道**現在有多少貨** → 庫存現況報表。
- 想知道**某段期間進出了什麼** → 庫存流水報表 / 採購、銷貨明細。
- 想知道**花了多少錢** → 成本摘要報表。
- 想知道**血檢花費 vs 血檢數據** → 血檢費用報表（錢）／血檢分析報表（數據趨勢）。

---

## 四、注意事項

- ⚠️ 報表數據來自已**核准**的單據；未核准單據不列入。
- ⚠️ 設定期間時注意起訖日，避免漏算或重複。
- 💡 「費用」與「分析」是兩份不同血檢報表，別混用。

## 📋 考題卷（可列印發給學員）

### 是非題（共 3 題）
1.（　）報表中心位於 ERP 選單下。
2.（　）成本摘要報表用於統計期間內的成本。
3.（　）血檢費用報表與血檢分析報表是同一份報表。

### 選擇題（共 4 題）
4. 想查「目前各品項即時庫存」，應看哪份報表？
   - (A) 庫存現況報表
   - (B) 銷貨明細報表
   - (C) 血檢分析報表
   - (D) 成本摘要報表
5. 想分析「血液檢查數據趨勢」，應看？
   - (A) 血檢費用報表
   - (B) 血檢分析報表
   - (C) 採購明細報表
   - (D) 庫存流水報表
6. 報表的數據主要來自？
   - (A) 所有單據（含未核准）
   - (B) 已核准的單據
   - (C) 草稿單據
   - (D) 已刪除的單據
7. 想看「某段期間的成本統計」，應選？
   - (A) 庫存現況報表
   - (B) 成本摘要報表
   - (C) 倉庫佈局
   - (D) 出勤匯出

## ✅ 標準答案與解析（講師用）

| 題號 | 答案 | 解析 |
|------|------|------|

| 2 | ✓ | 成本摘要＝期間成本統計。 |
| 3 | ✗ | 費用報表（錢）與分析報表（數據）不同。 |
| 4 | **A** | 庫存現況報表。 |
| 5 | **B** | 血檢分析報表看趨勢。 |

| 7 | **B** | 成本摘要報表。 |
