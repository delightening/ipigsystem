# iPig 系統教育訓練教材

本資料夾收錄各業務流程的教育訓練教材，每門課含**教材 + 紙筆考題卷（是非題 + 選擇題）+ 標準答案解析**。

- 完整課程地圖見 [`00_訓練課程總表.md`](./00_訓練課程總表.md)（全 40 門課規劃）。
- 列印學員考卷時，請移除各檔最後的「✅ 標準答案與解析（講師用）」段落。
- 及格標準依題數：6 題者答對 4 題（約 67%）、8 題者答對 6 題（75%）、10 題者答對 7 題（70%）。
