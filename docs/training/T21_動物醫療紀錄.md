# T21 ｜ 動物醫療紀錄

> **受眾**：試驗人員、獸醫師（VET）　**建議時長**：45 分鐘　**前置**：已完成 T20 動物進場與建檔、T02 電子簽章

## 學習目標

1. 在動物詳情頁建立各類醫療紀錄。
2. 操作觀察紀錄的完整欄位與附件上傳。
3. 善用時間軸、複製、版本歷史等輔助功能。

---

## 一、動物詳情頁 Tab 總覽

點動物耳號進入詳情頁，常用 Tab：

| Tab | 功能 |
|-----|------|
| 時間軸 | 所有紀錄時間序總覽，可檢視／編輯／複製／看歷史 |
| 觀察試驗紀錄 | 觀察、異常、試驗紀錄 + 附件 |
| 手術紀錄 | 手術過程、生理數值、麻醉時間，可 PDF 匯出 |
| 體重 | 體重追蹤，支援批次匯入 |
| 疫苗/驅蟲 | 接種與驅蟲紀錄 |
| 血液檢查 | 結果記錄、檢查項目模板/組合、趨勢圖 |
| 疼痛評估 | 疼痛分數評估 |
| 病理報告 | 病理組織報告上傳與管理 |

## 二、新增觀察紀錄

1. 進入 **觀察試驗紀錄** Tab → 「新增觀察」。
2. 填寫：**事件日期、紀錄性質（異常／試驗／觀察）、使用儀器、麻醉時間、內容、治療用藥**。
3. 可上傳**相片與文件附件**。
4. 儲存後顯示於時間軸。

> 💡 一筆紀錄填完儲存後會即時顯示在時間軸，方便接續新增下一筆。

## 三、輔助功能

- **複製紀錄**：以既有紀錄為範本快速新增。
- **版本歷史**：查看紀錄的修改軌跡。
- **血液檢查**：可建立檢查組合與預設值，結果以趨勢圖呈現。

---

## 注意事項
- ⚠️ 已電子簽章的醫療紀錄不可修改（見 T02）。
- ⚠️ 紀錄性質要選對（異常／試驗／觀察），影響後續統計與通報。
- 📋 各紀錄是否需先指派計畫見《動物紀錄計畫前置需求分類規範》：手術／犧牲採樣／疼痛評估／病理／觀察「試驗」性質**需已指派計畫**；體重／疫苗／血檢／觀察「異常·觀察」性質**免計畫**。

## 📋 考題卷（可列印發給學員）

### 是非題（共 5 題）
1.（　）動物詳情頁的時間軸可總覽所有紀錄並支援複製。
2.（　）觀察紀錄無法上傳相片或文件附件。
3.（　）手術紀錄可匯出為 PDF。
4.（　）血液檢查結果可用趨勢圖呈現。
5.（　）觀察紀錄儲存後會顯示在動物詳情的時間軸。

### 選擇題（共 5 題）
6. 下列何者**不是**觀察紀錄的填寫欄位？
   - (A) 事件日期　(B) 紀錄性質　(C) 治療用藥　(D) 供應商統編
7. 體重資料要大量帶入，最快的方式是？
   - (A) 逐筆手動輸入　(B) 批次匯入　(C) 寄信給管理員　(D) 拍照上傳
8. 紀錄性質**不包含**下列何者？
   - (A) 異常　(B) 試驗　(C) 觀察　(D) 報廢
9. 想查看某筆紀錄被改過幾次，應看？
   - (A) 版本歷史　(B) 倉庫佈局　(C) 角色權限　(D) 通知中心
10. 病理組織報告應在哪個 Tab 管理？
   - (A) 體重　(B) 疫苗/驅蟲　(C) 病理報告　(D) 疼痛評估
