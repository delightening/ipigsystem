# T10 ｜ 計畫申請書（AUP）撰寫與審查流程

> **受眾**：計畫主持人（PI）、試驗人員　**建議時長**：40 分鐘　**前置**：已完成 T01 登入與帳號安全

## 學習目標

完成本課後，您將能：
1. 獨立建立並提交一份 AUP 計畫申請書。
2. 說明 IACUC 五階段審查流程中，每個角色該做什麼。
3. 正確上傳/管理附件，並指派共同編輯人。
4. 回覆審查委員意見，直到計畫獲得核准。

---

## 一、流程總覽

AUP（Animal Use Protocol，動物使用計畫書）必須通過 IACUC 審查核准後，才能開始動物實驗。

| 階段 | 負責角色 | 主要動作 |
|------|----------|----------|
| ① 提交 | PI（計畫主持人） | 填寫計畫書各節內容並提交 |
| ② 預審 | IACUC 行政人員 | 初步審核完整性，指派審查委員 |
| ③ 審查 | 審查委員 / 獸醫師 | 逐項提出審查意見 |
| ④ 回覆 | PI | 針對每條意見逐條回覆或修正 |
| ⑤ 決議 | IACUC 主席 | 核准 / 要求修正 / 否決 |

> 只有走到「核准」，計畫才生效。被「要求修正」會退回步驟 ④ 重新回覆。
>
> 註：實際系統的「審查」階段可能再細分為行政預審補件、獸醫審查、補件重送等子狀態，本表為簡化的主流程。

---

## 二、操作步驟

### 2.1 建立計畫書
1. 側邊欄 → **AUP** → **計畫書管理** → 點「**新增計畫書**」。
2. 依序填寫各節內容。系統會**自動儲存草稿**，中途離開不會遺失。
3. 列表可依狀態（草稿、審查中、已核准）篩選，也支援即時搜尋與排序。

### 2.2 上傳附件
- 在編輯頁的「**附件**」區域，拖曳或點選檔案上傳。
- 支援格式：PDF、Word、Excel、圖片。
- **僅上傳者本人或管理員**可刪除附件。

### 2.3 指派試驗工作人員（Co-editor）
- **進入行政預審前，必須至少指派 1 位**試驗工作人員（Co-editor）；可再新增或移除，但不可為 0。

### 2.4 簽署申請須知
- 提交前需閱讀並**簽署當前生效版本的「申請須知」**，確認了解規範。

### 2.5 提交與 AI 審查輔助
1. 填寫完成後點「**提交**」，計畫進入 IACUC 審查流程。
2. 提交前可使用 **AI 審查輔助**做初步檢查，預先發現可能被退件的問題。

### 2.6 回覆審查意見
1. 收到審查意見後，進入計畫詳情逐條檢視。
2. 針對每一條意見**逐條回覆**或修改計畫內容後再送出。
3. 主席做出最終決議。

---

## 三、注意事項與常見錯誤

- ⚠️ **未簽署申請須知無法提交**。
- ⚠️ **未指派任何試驗工作人員（Co-editor）無法進入預審**。
- ⚠️ 計畫一旦提交進入審查，內容修改須依審查回覆機制，不能任意改動。
- ⚠️ 看不到「新增計畫書」？請確認您具備 PI 或相關角色（聯繫管理員指派）。
- 💡 善用自動存草稿，分次填寫長表單。

## 📋 考題卷（可列印發給學員）

### 是非題（每題 20 分，共 4 題）
1.（　）AUP 計畫書只要 PI 填好提交，不需經過審查就能開始動物實驗。
2.（　）審查委員提出意見後，PI 必須逐條回覆或修正才能繼續審查流程。
3.（　）計畫書的附件，任何使用者都可以刪除。
4.（　）提交計畫書前必須先簽署當前生效版本的「申請須知」。

### 選擇題（每題 20 分，共 4 題）
5. IACUC 審查的正確順序為何？
   - (A) 提交 → 審查 → 預審 → 決議 → 回覆
   - (B) 提交 → 預審 → 審查 → 回覆 → 決議
   - (C) 預審 → 提交 → 決議 → 審查 → 回覆
   - (D) 提交 → 決議 → 審查 → 回覆 → 預審

6. 計畫書提交後的「最終決議」由誰做出？
   - (A) 計畫主持人（PI）
   - (B) IACUC 行政人員
   - (C) IACUC 主席
   - (D) 倉庫管理員

7. 關於計畫書草稿，下列何者正確？
   - (A) 系統不會自動儲存，離開頁面就遺失
   - (B) 系統會自動儲存草稿，可分次填寫
   - (C) 草稿一律只能填一次，不能修改
   - (D) 草稿不支援搜尋與篩選

8. 下列何者**不是**計畫書附件支援的格式？
   - (A) PDF
   - (B) Word
   - (C) Excel
   - (D) 可執行檔（.exe）
